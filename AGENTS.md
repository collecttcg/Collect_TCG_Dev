# Collect TCG engineering

At the start of each task, including a new chat, read the current `COLLECT_TCG_BASELINE.md` from GitHub `main` and check the repository HEADs. Use the live repository state and immutable release manifests to reconcile older project attachments or chat notes.

Development is the working environment. Production changes and promotion require explicit authorization.

After meaningful engineering, release, or database changes, update the narrative baseline for each affected environment in the same work. Record what changed, what was validated, relevant limitations, and deployment or migration evidence. Keep immutable release manifests and historical facts intact. The baseline workflow maintains its marked GitHub state section. Keep manual notes outside those markers.
